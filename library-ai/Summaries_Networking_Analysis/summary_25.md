# Lecture Summary on Network Theory Applications

## Key Topics Discussed
* **Criminal Networks**
  - Definition: A criminal network is a group of individuals interconnected through illegal activities, often analyzed to apprehend criminals.
  
* **Node Centrality**
  - Degree Centrality: A measure of the number of direct connections a node has in a network.
  - Betweenness Centrality: A metric that captures the extent to which a node lies on the shortest paths between other nodes, indicating its control over information flow.
  - Eigenvector Centrality: A measure of a node's influence in a network based on the importance of its connections.

* **Network Dynamics**
  - Description of how nodes can shift in importance over time within a network, illustrated with examples from criminal organizations.
  
* **Research Applications**
  - Application of network analysis methods in various domains, including criminology and genetic research (e.g., autism).
  
* **Steiner Trees**
  - Definition: A method to find the minimal connecting network for a set of nodes, used in identifying potential links within networks like those for genes associated with autism.

## Summary
This lecture explores network theory's applications in criminal networks and genetic research, emphasizing centrality measures and network dynamics.
